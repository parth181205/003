## 💡 How the Game Handles Images
The game code includes **automatic visual fallback renders**. If you haven't placed an image file into `public/images/escape_room/` yet, the game will automatically display a beautiful stylized canvas so that the game is **100% playable immediately**, and as soon as you add your generated PNG files, they will appear seamlessly!
